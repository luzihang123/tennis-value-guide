# 网球划算学

一本关于怎样更划算地打网球的开放电子书。场地、装备、学习和约球都算成本；时间、便利和打球体验也算收益。

本书面向想开始打球、希望长期打下去，或正在比较不同选择的球友。内容先从通用方法写起，再逐步补充各城市的实地信息。**上海是第一个城市篇，不是本书的范围。**

## 本书怎样写

- 先说适合谁、要解决什么问题，再给可执行的选择方法。
- 同时说明金钱、时间和隐藏成本；不把“最便宜”直接等同于“最划算”。
- 对价格、开放时间、预约规则等易变信息标明来源与核验日期。
- 区分亲身体验、可核验事实和个人判断；不确定的地方明确写出。
- 不收录未经核实的商家推荐，也不以单一品牌或城市为中心。

## 生成电子书

下载草稿：[EPUB](dist/网球划算学.epub) · [单文件 HTML](dist/网球划算学.html)

正文以 Markdown 为准。安装 [Pandoc](https://pandoc.org/installing.html) 后运行：

```sh
python3 tools/build_ebook.py
```

脚本按固定目录顺序更新 `dist/网球划算学.epub` 和 `dist/网球划算学.html`。现阶段章节主要是写作提纲，导出文件也是草稿版。
