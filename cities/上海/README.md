# 上海

按一次打球从准备到参与社区活动的顺序阅读：

1. [订场](01-订场.md)：先找到合适的场地。
2. [约球](02-约球.md)：找到一起打球的人。
3. [教练](03-教练.md)：需要系统学习时找指导。
4. [陪练](04-陪练.md)：增加对打和喂球练习。
5. [网球墙](05-网球墙.md)：一个人也能练。
6. [发球机与练习场](06-发球机与练习场.md)：做重复练习。
7. [试拍与租拍](07-试拍与租拍.md)：购买前体验装备。
8. [穿线](08-穿线.md)：维护球拍。
9. [赛事与活动](09-赛事与活动.md)：参与比赛和社群活动。

本页以公开资料作起点，尚未形成覆盖全市的实测清单。
