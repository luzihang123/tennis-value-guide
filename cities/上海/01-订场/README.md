# 上海：订场

> 通用方法：[场地与订场](../../../book/02-场地与订场.md)

## 从哪里找

上海市政府的[场馆查找说明](https://english.shanghai.gov.cn/en-Individuals-DailyLife-Fitness/20260813/e23b543680f64e8c89ecdd44a3983831.html)介绍了“上海体育”微信公众号的“服务 → 健身地图”入口；可按场馆、社区体育设施等类别查找。具体能否在线订场，以当前页面和场馆公告为准。

## 两个公开价格例子

| 场馆 | 已公示的网球价格 | 适合怎样比较 |
| --- | --- | --- |
| 长宁网球场，华山路1038弄173号 | 周末及法定节假日 7:00–8:00 公益时段，60 元/小时 | 能早起且交通方便时可比较；[2026-05 公告](https://www.shcn.gov.cn/col6991/20260502/1309141.html) |
| 乐动虹桥，娄山关路445弄 | 学练场工作日上午 12:00 前 75 元/小时，其余时段 130 元/小时；标准场分别为 300、380 元/小时 | 先确认学练场是否符合你的练习需求；[2026-06 价格公告](https://www.shcn.gov.cn/col5959/20260624/1313010.html)、[地址与场地说明](https://www.shcn.gov.cn/col6991/20260508/1309302.html) |

以上是**公示价格，不是到访实测**。本文于 2026-10-04 核对网页；下单前请再次确认实时价格、预约入口、取消及雨天规则。不要只按每小时价格排名，通勤和上场人数也会改变实际成本。
