# 从其他球类学习网球

有其他球类基础，通常更容易理解节奏、落点和空间；具体挥拍动作仍要重新学。下面是**练习类比**，不是动作等式。

| 原有经验 | 可借用的感觉 | 网球里要重新适应 |
| --- | --- | --- |
| 羽毛球扣杀 → 发球 | 高点击球、身体协调 | 网球有抛球、球更重，握拍和挥拍路径不同 |
| 乒乓球 → 底线击球 | 旋转、击球时机、落点 | 距离更长，更多用脚步和全身参与 |
| 匹克球 → 网前球 | 预判和拍面控制 | 球速、弹跳、场地与挥拍幅度不同 |

方法是先找一个共通点，再专练一个差异。例如有羽毛球基础的人，先单独练网球抛球和轻发球，不急着把扣杀动作照搬。反过来，网球练出的移动与落点判断，也能帮助尝试其他球类。
