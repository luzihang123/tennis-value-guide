# 技术与练习

练习先追求**可重复**，再追求速度和力量。每次只选一个主要目标，记录结果，下次能复现才算学会。

- [基础动作](基础动作.md)：先能把球稳定打到目标区域。
- [单人练习](单人练习.md)：没有球友时怎么练。
- [练习计划](练习计划.md)：把练习安排进每周时间。
- [从其他球类学习网球](从其他球类学习网球.md)：借用已有经验，也识别差异。

USTA 的[教学目录](https://www.usta.com/en/home/improve/tips-and-instruction.html)有握拍、正反手、发球和热身的入门示范；文字只能提示观察点，动作问题最好结合视频或现场反馈。
